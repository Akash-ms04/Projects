# Tableau Capstone Project - 
Logistics Dashboard

## Project Summary
This Tableau capstone project analyzes logistics order performance across revenue, delivery efficiency, shipping cost, warehouse operations, and customer satisfaction. The dashboard uses a cleaned logistics dataset to help business users monitor KPIs, identify late-delivery patterns, compare carrier performance, evaluate discount impact, and understand warehouse and driver workload.

## Key Insights
- Total revenue is approximately 487.6M, with around 4.9K orders analyzed across the dashboard period.
- Delivery performance needs attention, with average delivery days around 15.15 and late deliveries representing a major operational risk.
- Discount impact is significant, making net revenue analysis important alongside gross revenue.
- Carrier, region, warehouse, and driver-level views help identify operational bottlenecks and workload imbalance.

## Features Used
- Dashboard Actions
- Table Calculation
- Story Page (if added)
- Filters and slicers for Year, Carrier, Category, Region, Country, Status, Priority, and Warehouse
- Calculated fields for Gross Revenue, Net Revenue, On-Time Rate, Late Delivery Rate, Discount Impact, and Average Delivery Days
